Operating Time Rules

  • Display local time using the airport’s actual time zone.
  • Use Zulu/UTC time in 24-hour format, without AM/PM.
  • Display the local date when a time-zone change crosses midnight.
  • MMLO is the main hub; MMQT is an alternate, not an automatic replacement.
  • Validate aircraft compatibility with the runway, range, and airport conditions.

Live schedules require a real time and time-zone source; they are not simulated as real-time data.
