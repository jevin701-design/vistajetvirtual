# VistaJet Group Virtual — archivos disponibles para GitHub

## Contenido

- `index.html`: copia exacta del único archivo web disponible en el proyecto montado (`vjg-fms.html`), renombrada como página de entrada para GitHub Pages.

La página actual es un Flight Desk para Infinite Flight, con generador de ruta, mapa esquemático, tramos, cálculos estimados de tiempo y combustible, importación/exportación de planes y almacenamiento local de coordenadas personalizadas.

## Alcance y cambios pendientes

Este paquete refleja únicamente los archivos disponibles. No contiene la web completa de VistaJet Group Virtual ni implementa cambios recientes que no estén presentes en el material montado. En particular, faltan:

- páginas de inicio, flota y hubs con texto coherente en español e inglés;
- fichas técnicas de aeronaves e imágenes;
- eliminación de las especificaciones Airbus A380 duplicadas;
- corrección de la visualización de hora Zulu y hora local en hubs.

El generador de vuelos existente está incluido tal como estaba en el archivo fuente disponible.
